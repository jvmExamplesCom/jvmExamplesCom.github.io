Converting Java float Primitive Value to Float Object Example

Java utilizes both primitive data types and object-oriented classes for the programming language. Primitive data types are the basic values, such as integers, characters, booleans, and floats. The more complex objects utilize classes. Below is an example of how to convert a primitive float value in Java to a Float object.

Example

In this example, we will create a class that has a primitive float value and a Float object value. We will use a float literal to initialize the primitive float value and use the Float wrapper to initialize the Float object. After initializing the primitive float value, we will then call the Float wrapper’s constructor to convert the primitive float value into a Float object: 

          
           
public class PrimitiveToFloatObject {
    private float primitiveFloatValue;
    private Float floatObjectValue;

    public PrimitiveToFloatObject(float primitiveFloatValue) {
        // Initialize the primitive float value
        this.primitiveFloatValue = primitiveFloatValue;

        // Convert the primitive float value to a Float object
        this.floatObjectValue = new Float(this.primitiveFloatValue);
    }
}
