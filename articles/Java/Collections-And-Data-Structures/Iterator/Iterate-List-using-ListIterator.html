Iterating List Using ListIterator In Java

Java provides a convenient way of iterating over the elements of a List using ListIterator. A ListIterator has methods to traverse the list in either direction, obtain the next and previous element and their indices and check if the list has more elements or not.

How to Use A ListIterator In Java?

We can use a ListIterator to iterate over a List in Java. We need to create a ListIterator by passing a List to its constructor. As shown below: 

          
           
List<String> list = new ArrayList<>();
list.add("One");
list.add("Two");
list.add("Three");
 
ListIterator<String> listIterator = list.listIterator();
Once the ListIterator is created, we can use it to traverse the List in either directions, obtain the next and previous element and their indices and check if there are more elements in the List or not. The code snippet below shows how to use a ListIterator to iterate over a List. 

          
           
while (listIterator.hasNext()) {
    System.out.println(listIterator.next());
}

while (listIterator.hasPrevious()) {
    System.out.println(listIterator.previous());
}

Example Of Iterating List In Java Using ListIterator

Let’s take an example to understand how we can use a ListIterator to iterate over a List in Java. Given below is the example code which creates a List of Strings and then uses a ListIterator to iterate over the List in both forward and backward direction. 

          
           
List<String> list = new ArrayList<>();
list.add("One");
list.add("Two");
list.add("Three");
 
ListIterator<String> listIterator = list.listIterator();
 
System.out.println("Forward Direction Iteration:");
while (listIterator.hasNext()) {
    int position = listIterator.nextIndex();
    String item = listIterator.next();
    System.out.printf("Position %d = %s%n", position, item);
}
 
System.out.println("Backward Direction Iteration:");
while (listIterator.hasPrevious()) {
    int position = listIterator.previousIndex();
    String item = listIterator.previous();
    System.out.printf("Position %d = %s%n", position, item);
}
When the above code is executed, it produces the following output. 

          
           
Forward Direction Iteration:
Position 0 = One
Position 1 = Two
Position 2 = Three
Backward Direction Iteration:
Position 2 = Three
Position 1 = Two
Position 0 = One
