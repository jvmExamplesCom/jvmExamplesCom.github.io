How to Print TreeMap in Java

TreeMap is a data structure that is used to store key-value pairs of data, where the keys are always sorted and cannot contain duplicates. In this article, we will learn how to print out the elements of a TreeMap in Java.

Using the forEach() Method

The simplest way to iterate through a TreeMap is to use the forEach() method, which takes a consumer as an argument. A consumer is a functional interface that takes an argument of the same type as the TreeMap and performs some operation on it. For example, if we have a TreeMap of integers, we can use the consumer to print out each element of the TreeMap in a loop: 

          
           
TreeMap<integer,integer> treeMap = new TreeMap<>();
treeMap.put(1, 10);
treeMap.put(2, 15);
treeMap.put(3, 11);

treeMap.forEach((k,v) -> {
    System.out.println(k + " : " + v);
});</integer,integer>
This code will print out the following output: 

          
           
1 : 10
2 : 15
3 : 11

Using the KeySet() Method

The KeySet() method returns a Set containing all the keys of the TreeMap. We can then iterate through this set using an iterator and access the value of the key using the get() method. For example, we could print out the elements of our TreeMap from the previous example using the KeySet() method like so: 

          
           
Set<integer> keys = treeMap.keySet();

Iterator<integer> iterator = keys.iterator();
while (iterator.hasNext()) {
    int key = iterator.next();
    int value = treeMap.get(key);
    System.out.println(key + " : " + value);
}</integer></integer>
Which will produce the same output as before: 

          
           
1 : 10
2 : 15
3 : 11
