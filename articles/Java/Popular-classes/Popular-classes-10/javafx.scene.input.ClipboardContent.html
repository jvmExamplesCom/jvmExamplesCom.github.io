Introduction to javafx.scene.input.ClipboardContent

The 

          
           
javafx.scene.input.ClipboardContent
class is a part of the JavaFX API, and it provides methods and fields for managing a data structure used by the system clipboard. The content is stored in a 

          
           
HashMap<DataFormat, Object>
and arranged according to the type of 

          
           
DataFormat
associated with each 

          
           
Object
.

There are a few methods that can be used when working with 

          
           
javafx.scene.input.ClipboardContent
. Here are some of them:

put()

The 

          
           
put()
method is used to insert a new entry into the clipboard content. It takes two parameters: 

          
           
public void put(DataFormat key, Object value) {
        this.data.put(key, value);
    }
where 

          
           
key
is the type of 

          
           
DataFormat
associated with 

          
           
value
, which is the object content to be stored.

get()

The 

          
           
get()
method is used to retrieve an entry from the clipboard content. It takes one parameter, a 

          
           
DataFormat

Object
representing the content associated with the given 

          
           
DataFormat
. 

          
           
public Object get(DataFormat key) {
        return this.data.get(key);
    }

clear()

The 

          
           
clear()
method is used to clear all entries from the clipboard content. It does not take any parameters and does not return anything.

        this.data.clear();
