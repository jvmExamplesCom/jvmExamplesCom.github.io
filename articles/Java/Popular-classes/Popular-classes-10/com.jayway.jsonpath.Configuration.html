Introduction to com.jayway.jsonpath.Configuration in Java

The isIncludeNullOnPathNotFound() method returns true if null values should be included when a JsonPath path is not found. The isCollectionLimitSet() method returns true if a collection limit has been set. The getCollectionLimit() method returns the collection limit if it has been set. The isPathLeafToNull() method returns true if leaves of a path should be returned as null values. The isPathDropEmptyArraysSet() method returns true if paths will drop empty arrays. The getPathDropEmptyArraysLimit() method returns the maximum number of empty arrays dropped by the path. The isGlobalSettingEnabled() method returns true if global settings should be enabled. The isPathsValidationDisabled() method returns true if path validation should be disabled.
