Introduction to org.apache.curator.framework.recipes.cache.PathChildrenCacheEvent

Features of PathChildrenCacheEvent

PathChildrenCacheEvent also provides additional information about the changes it detected, such as the type of the change, the path of the node that was changed and the data associated with the node.

Use Cases

PathChildrenCacheEvent can be used to monitor changes in ZooKeeper and generate events when those changes occur.
