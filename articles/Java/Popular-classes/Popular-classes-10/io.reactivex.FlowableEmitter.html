io.reactivex.FlowableEmitter

FlowableEmitter is part of the io.reactivex package and provides a way for developers to easily handle backpressure when dealing with different sources of reactive data, such as a database, web server, or message queue. This ensures that any changes made to data are delivered in an efficient and predictable manner.

FlowableEmitter is used in conjunction with a Flowable to generate a reactive stream of values. The Flowable can be configured to emit these values when they become available, while the FlowableEmitter handles backpressure, ensuring that the values are not emitted until the downstream consumers can actually handle them. This allows developers to create reactive applications that have a steady flow of data, even when working with potentially high traffic sources.

Creating a FlowableEmitter

Creating a FlowableEmitter is easy. The following code creates a FlowableEmitter and then sets it up to emit integers from 1 to 10:


          
           
FlowableEmitter<Integer> emitter = Flowable.create(emitter -> {

    emitter.onComplete();
