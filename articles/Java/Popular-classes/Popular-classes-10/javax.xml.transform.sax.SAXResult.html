javax.xml.transform.sax.SAXResult

The javax.xml.transform.sax.SAXResult class is a Result implementation that is used to write an XML document to an instance of the org.xml.sax.ContentHandler interface. It functions as an adapter between a SAX2 parser and a destination for an XML document.

Creating Instance

A SAXResult object can be created using the following constructor: 

          
           
public SAXResult(ContentHandler handler) { ... }
This creates a new SAXResult object with the specified ContentHandler.

Methods

SAXResult class has the following methods:
  • public void setSystemId(String systemId) - Sets the system identifier.
  • public String getSystemId() - Gets the system identifier.
  • public void setHandler(ContentHandler handler) - Sets the ContentHandler.
  • public ContentHandler getHandler() - Gets the ContentHandler.

Example

This example demonstrates how to create a SAXResult object and use it to transform a document: 

          
           
File xslFile = new File("stylesheet.xsl");
File xmlFile = new File("document.xml");

Source xslSource = new StreamSource(xslFile);
Source xmlSource = new StreamSource(xmlFile);
