org.apache.hadoop.io.Text Class in Java

The org.apache.hadoop.io.Text class is an important utility class used in Apache Hadoop for text manipulation. It is a subclass of org.apache.hadoop.io.WritableComparable and holds UTF-8 encoded character sequence data. The Text class provides methods to convert the text sequence into different forms, for example, converting it to binary form, reading or writing text to or from the filesystem, and so on.

Text Class Constructors

The org.apache.hadoop.io.Text class provides multiple constructors depending on the type of data to be manipulated. To create an empty Text object, you can use the default constructor: 

          
           
Text txt = new Text();
You can also construct a new Text object to wrap a given String: 

          
           
String str = "This is a test string.";
Text txt = new Text(str);
And, you can construct a new Text object to wrap a given byte array: 

          
           
byte[] b = {'a','b','c','d','e','f'};
Text txt = new Text(b);

Text Class Methods

The org.apache.hadoop.io.Text class provides several methods for manipulating text. Here are some of the most commonly used methods: 

          
           
getLength(): Returns the length of the wrapped character sequence.

          

          
           
Text txt = new Text("Hello");
int len = txt.getLength();
System.out.println(len);
// Output: 5

          

          
           
charAt(): Returns the character at the given position.

          

          
           
Text txt = new Text("Hello");
char ch = txt.charAt(3);
System.out.println(ch);
// Output: l

          

          
           
find(): Returns the index of the first occurrence of the given character in the text.

          

          
           
Text txt = new Text("Hello");
int ind = txt.find('l');
System.out.println(ind);
// Output: 2

          

          
           
getBytes(): Returns the underlying byte array for this Text object.

          

          
           
byte[] b = {'h', 'e', 'l', 'l', 'o'};
Text txt = new Text(b);
byte[] b2 = txt.getBytes();
System.out.println(Arrays.toString(b2));
// Output: [h, e, l, l, o]

          

          
           
set(): Sets the contents of the Text object with the given Text object or byte array.

          

          
           
Text txt1 = new Text("Hello");
Text txt2 = new Text("World");
txt1.set(txt2);
System.out.println(txt1);
// Output: World
