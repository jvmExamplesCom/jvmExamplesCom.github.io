javax.xml.bind.annotation.XmlType

javax.xml.bind.annotation.XmlType is an annotation type used to map a class or an enum type to the XML representation. It can be used to customize the name and the ordering of the elements and attributes in the XML representation.

Example 1: Customizing Class Name, Element Names, and Order

In this example, we will customize the class name, element names, and order using XmlType. We will use a Customer class with fields for customerName and address.


          
           
@XmlType(propOrder = {"customerName", "address"})
public class Customer {
    private String customerName;
    private String address;

    public String getCustomerName() {
        return customerName;
    }
    public void setCustomerName(String customerName) {
        this.customerName = customerName;
    }
    public String getAddress() {
        return address;
    }
    public void setAddress(String address) {
        this.address = address;
    }
}

The @XmlType annotation specifies the ordering of the elements in the XML output. The propOrder value is an array of strings containing the XML element names in the order that they should appear in the XML output.

By default, the class name will be used as the root element of the XML output. If a different element name is desired, then the name attribute of @XmlType can be used to specify it.

Example 2: Customizing Attribute Names and Types

In this example, we will customize the attribute names and types using XmlType. We will use a Customer class with fields for customerName, address, and dateOfBirth.


          
           
@XmlType(name="CustomerInfo", propOrder = {"customerName", "address", "dateOfBirth"})
public class Customer {
    private String customerName;
    private String address;
    private Date dateOfBirth;

    public String getCustomerName() {
        return customerName;
    }
    public void setCustomerName(String customerName) {
        this.customerName = customerName;
    }
    public String getAddress() {
        return address;
    }
    public void setAddress(String address) {
        this.address = address;
    }
    public Date getDateOfBirth() {
        return dateOfBirth;
    }
    public void setDateOfBirth(Date dateOfBirth) {
        this.dateOfBirth = dateOfBirth;
    }
}

By default, the fields of the class will be mapped to the XML elements. In this example, the dateOfBirth field will be mapped to an XML element since it is listed in the propOrder attribute of the @XmlType annotation.

If we want the dateOfBirth field to be mapped to an XML attribute instead of an XML element, we can use the attribute attribute of the @XmlType annotation to customize the mapping.


          
           
@XmlType(name="CustomerInfo", propOrder = {"customerName", "address"}, attribute="dateOfBirth")
public class Customer {
    // ...
}

Now, the dateOfBirth field is mapped to an XML attribute instead of an XML element.

@XmlType(name="CustomerInfo", propOrder = {"customerName", "address"}, attribute=@XmlAttribute(name="dateOfBirth", type=Date.class))

Now, the dateOfBirth field is mapped to an XML attribute named “dateOfBirth” with a data type of Date.
