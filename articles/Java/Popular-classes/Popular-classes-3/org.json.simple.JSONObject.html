Introduction to org.json.simple.JSONObject

The org.json.simple.JSONObject is a java library that helps developers work with JSON data structures. It provides an easy way to parse, store and manipulate JSON data. This library is designed to be lightweight and simple to use, making it the perfect choice for projects where you need to quickly get up and running with JSON.

Using org.json.simple.JSONObject

To get started working with org.json.simple.JSONObject, you'll need to first create a new instance. You can do this by providing your JSON data as a string or as a File object:


          
           
String jsonData = "{\"name\":\"Bob\",\"age\":21}";
JSONObject obj = new JSONObject(jsonData);
Alternatively, you can use the 
fromFile()
method to read your JSON data from a file: 

          
           
JSONObject obj = JSONObject.fromFile("data.json");

Once you have created your JSONObject instance, you can use it to access your JSON data. To access values based on their key, you can use the 

get()
method: 

          
           
String name = obj.get("name"); // "Bob"
You can also use the 
put()
method to add new values to the JSONObject instance: 

          
           
obj.put("height", 180); // {"name":"Bob","age":21,"height":180}
