org.apache.http.client.utils.URIBuilder

The org.apache.http.client.utils.URIBuilder class is a utility class for constructing URIs in a safe manner, providing advanced features such as encoding and automatic addition of query parameters.

Usage

The URIBuilder class provides two constructors, one accepting a base URI and one accepting a complete URI string.


          
           
// Create a UriBuilder from a base Uri
URI baseUri = new URI("https://example.com/");
URIBuilder uriBuilder = new URIBuilder(baseUri);

// Create a UriBuilder from a complete Uri string
String uriString = "https://example.com/?param1=value1";
URIBuilder uriBuilder = new URIBuilder(uriString);

The URIBuilder class provides methods for constructing individual components of a URI, as well as methods for adding query parameters. All of the methods return a reference to the same object, so they can be chained together.


          
           
// Add a single query parameter

URIBuilder uriBuilder = new URIBuilder("https://example.com/")
