org.springframework.beans.BeansException

org.springframework.beans.BeansException is an exception thrown when a bean could not be created from the given definition in the XML configuration file or when a matching dependent bean could not be found. It is a sub-class of RuntimeException and is thrown by the Spring framework during bean creation.

Examples of org.springframework.beans.BeansException

The following code example tries to create a bean called 'myBean' with a dependency pointing to another bean called 'dependentBean'. Since the 'dependentBean' is not defined, an exception is thrown at runtime:


          
           
public class TestBean {
    private DependentBean dependentBean;

    public static void main(String[] args) {
        ApplicationContext context = new ClassPathXmlApplicationContext("beans.xml");
        TestBean testBean = context.getBean("myBean", TestBean.class);
    }
}
The corresponding beans.xml file: 

          
           
<bean id="myBean" class="com.example.TestBean">

</bean>

org.springframework.beans.factory.NoSuchBeanDefinitionException: No bean named 'dependentBean' available
This exception is caused by the 

          
           
org.springframework.beans.BeansException
. It is thrown when the Spring framework cannot find the dependent bean definition in the XML configuration file.

Handling org.springframework.beans.BeansException
