Java Security KeyStore

The Java Security KeyStore is a platform independent secure storage facility that provides an encryption mechanism for storing sensitive information like private keys, passwords, and certificates. It can store both symmetric and asymmetric key pairs. Java KeyStore was introduced in Java 1.2 and is available in all versions of Java since then. It supports the storage of a wide range of cryptographic objects, and makes it easy to manage their lifecycle.

Creating a KeyStore

A new Java KeyStore can be created by using the 

          
           
KeyStore.getInstance()
method. This method will return an instance of KeyStore for the specified type. The following example creates a 
KeyStore
instance with the type of 
JKS
: 

          
           
KeyStore ks = KeyStore.getInstance("JKS");

Loading the KeyStore

The 
load()
method must be used to load the KeyStore before it can be used. This method takes an 
InputStream
as a parameter, which is typically a file or a byte array. The following example uses a 
FileInputStream
to load the KeyStore: 

          
           
FileInputStream fis = new FileInputStream("keystore.jks");
ks.load(fis, "password".toCharArray());
fis.close();

Saving the KeyStore

The 
store()
method must be used to save the KeyStore. This method takes an 
OutputStream
as a parameter, which is typically a file or a byte array. The following example uses a 
FileOutputStream
to save the KeyStore: 

          
           
FileOutputStream fos = new FileOutputStream("keystore.jks");
ks.store(fos, "password".toCharArray());
fos.close();

Storing and Retrieving Keys

Once the KeyStore has been loaded and saved, it can be used to store and retrieve keys. The 

setKeyEntry()
and 
getKey()
methods can be used to store and retrieve keys from the KeyStore. The 
setKeyEntry()
method requires the key name, the key, and the password used to protect the key. The following example stores an RSA key in the KeyStore: 

          
           
KeyPairGenerator kpg = KeyPairGenerator.getInstance("RSA");
KeyPair kp = kpg.generateKeyPair();
ks.setKeyEntry("myKey", kp.getPrivate(), "password".toCharArray(), null);
// returns PrivateKey object
PrivateKey privateKey = (PrivateKey) ks.getKey("myKey", "password".toCharArray());
