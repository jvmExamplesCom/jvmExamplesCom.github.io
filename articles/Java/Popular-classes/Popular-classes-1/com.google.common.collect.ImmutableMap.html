Introduction to com.google.common.collect.ImmutableMap

ImmutableMap is an interface in the Java library com.google.common.collect that provides a map construct with built-in features for thread safety, enforced immutability, great flexibility, and other features.

Creating an ImmutableMap

An ImmutableMap can be created using the static factory method 


          
           
ImmutableMap.of()
. It requires either two or four parameters (two parameter version is for a single key-value pair). The two parameter version is used when we want to create a map with one element directly without any additional methods. Example: 

          
           
ImmutableMap<String, Integer> map = ImmutableMap.of("key", 5);

The four parameter version is used when we want to create a map with multiple elements. It will take two arrays of type key and value respectively as arguments.

Example: 

          
           
String[] keys = {"key1", "key2"};
Integer[] values = {5, 10};
ImmutableMap<String, Integer> map = ImmutableMap.of(keys, values);

An ImmutableMap can also be created from a preexisting Map instance. The static factory method 


          
           
ImmutableMap.copyOf(map)
takes a Map instance as argument and creates an ImmutableMap from it. Example: 

          
           
HashMap<String, Integer> hashMap = new HashMap<>();

ImmutableMap<String, Integer> map = ImmutableMap.copyOf(hashMap);

Using an ImmutableMap

An ImmutableMap is like a regular Map but with some key differences. First, it cannot be modified once it is created, hence the name “Immutable”. Also, the ImmutableMap is thread-safe. This means that multiple threads can access the same ImmutableMap without any data corruption.

The ImmutableMap has several useful methods which allow us to query and manipulate the data inside the ImmutableMap. For example, the 


          
           
containsKey
method allows us to check if a given key is present in the ImmutableMap in O(1) time complexity. We can use this to check if a certain value exists in the Map before we perform any operation on it. Example: 

          
           
if (map.containsKey("key1")) {
    int value = map.get("key1");
    System.out.println(value); // 5

method. This method returns the number of key-value pairs in the ImmutableMap in O(1) time complexity. Example: 

          
           
System.out.println(map.size()); // 2
