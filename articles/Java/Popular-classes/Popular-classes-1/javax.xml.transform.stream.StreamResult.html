Introduction to javax.xml.transform.stream.StreamResult

javax.xml.transform.stream.StreamResult is an abstract class that is a subclass of org.xml.transform.Result and serves as the destination for a transformation result.

The StreamResult class reads data into a byte-stream from a source and then creates a string representation of the data which can be parsed as XML.

This class is useful for transforming XML documents into other formats such as HTML, RTF, or XSLT.

Syntax of StreamResult Class


          
           
public abstract class StreamResult extends Result

In the following example, we will create an instance of the StreamResult class and use it to transform a source XML document into the HTML format.

public class Test {

  public static void main(String[] args) {

    String sourceFile = "source.xml";
    String resultFile = "result.html";

    StreamSource source = new StreamSource(sourceFile);
    StreamResult result = new StreamResult(resultFile);

    TransformerFactory transformerFactory = TransformerFactory.newInstance();
    Transformer transformer = transformerFactory.newTransformer();

  }

}

We then create an instance of the TransformerFactory, which is used to generate a Transformer object by calling the newTransformer() method. Finally, we call the transform() method on the Transformer object to perform the transformation.
