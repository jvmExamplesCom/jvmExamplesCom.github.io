android.app.ActivityManager

The android.app.ActivityManager is an Android system service that provides a range of tasks related to managing activities, services, and the application processes. It is primarily used by developers for debugging and to control application resource usage.

Basic Methods

The ActivityManager class provides basic methods for starting, stopping and getting details about activities, processes and services. 

          
           
ActivityManager activityManager = (ActivityManager) getSystemService(ACTIVITY_SERVICE);

Starting an Activity

To start an Activity in the current application, use the startActivity() method: 

          
           
Intent intent = new Intent(this, ExampleActivity.class);
activityManager.startActivity(intent);

Stopping an Activity

To stop an Activity in the current application, use the finishActivity() method: 

          
           
activityManager.finishActivity(Activity.RESULT_CANCELED);

Getting Details about an Activity

To get details about an Activity in the current application, use the getRunningTasks() method: 

          
           
List<RunningTaskInfo> runningTasks = activityManager.getRunningTasks();
