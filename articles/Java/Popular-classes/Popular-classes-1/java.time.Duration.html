Introduction to Java.time.Duration

Java.time.Duration is a class in the Java Standard Edition 8 date-time package (java.time). Duration is designed to store time as a number of seconds and nanoseconds. Durations are commonly used to measure durations between two points in time, such as the time taken for an operation to complete.

Creating a Duration

A Duration can be created by passing the two points in time, or by providing the total duration:


          
           
// Create a Duration between two points in time
LocalDateTime start = LocalDateTime.now();
LocalDateTime end = LocalDateTime.now().plusSeconds(60);
Duration duration = Duration.between(start, end);

// Create a Duration of one minute
Duration duration = Duration.ofMinutes(1);

Methods of the Duration Class

The Duration class offers methods that return different representations of the duration. For example, you can check the length of the duration in seconds, nanoseconds, or days. 


          
           
// Get length of duration in seconds
long seconds = duration.getSeconds();

// Get length of duration in nanoseconds
long nanos = duration.getNano();

// Get length of duration in days
long days = duration.toDays();

Adding/Subtracting Duration

Duration newDuration = duration.plusSeconds(10);
