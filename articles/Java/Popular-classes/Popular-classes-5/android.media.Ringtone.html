android.media.Ringtone

Android provides Ringtone class to help developers play ringtones, notification tones and alarms in their applications. It is part of the 

          
           
android.media
package. The Ringtone class has various methods which are useful for managing the ringing of the device.

Getting a Ringtone Instance

The first step is to get a ringtone instance which can be done by calling the static 

          
           
getRingtone
method which takes in two parameters: the context object and the ringtone URI which can be obtained from the RingtoneManager class. 

          
           
Ringtone ringtone = RingtoneManager.getRingtone(context, RingtoneManager.getDefaultUri(RingtoneManager.TYPE_RINGTONE));

Playing and Stopping a Ringtone

Once an instance of Ringtone is obtained, it can be used to play and stop the device's ringtone. This can be done using the 

          
           
play()
and 

          
           
stop()
methods. 

          
           
ringtone.play();
ringtone.stop();

Getting the Ringtone's Title

The 

          
           
getTitle()
method of the Ringtone class can be used to get the title of the ringtone. 

          
           
String title = ringtone.getTitle();

Setting the Volume of a Ringtone

The volume of the ringtone can be set using the 

          
           
setVolume()
method. The parameter is a float value between 0.0f and 1.0f. 

          
           
ringtone.setVolume(0.5f);

Destroying a Ringtone Instance

It is important to destroy the ringtone instance once it is no longer needed as this will free up memory. This can be done by calling the 

          
           
release()
method. 

          
           
ringtone.release();
