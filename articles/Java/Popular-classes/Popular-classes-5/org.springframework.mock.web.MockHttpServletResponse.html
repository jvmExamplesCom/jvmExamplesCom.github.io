Introduction to MockHttpServletResponse

The 

          
           
org.springframework.mock.web.MockHttpServletResponse
class is a tool provided by the Spring framework for testing servlets and web applications. It provides a convenient way to simulate HTTP requests and responses without having to actually hit an HTTP server. This is useful when unit testing code that relies on an HTTP response, such as AJAX calls. In this article, we will explore how to use the MockHttpServletResponse class to test these types of applications.

Creating a Basic MockHttpServletResponse

Creating a MockHttpServletResponse is easy. All you have to do is call the constructor, passing in the request object that you wish to mock.


          
           
MockHttpServletResponse response = new MockHttpServletResponse(request);

Setting Response Headers

You can set response headers using the 
setHeader()
method. For example, to set the response code to 200, you can do this: 

          
           
response.setHeader("HTTP/1.1", "200 OK");

You can also set other response headers like content type, content length, etc. using the same method.

Setting the Response Body

To set the response body, you can use the 
setContent()
method. This method takes a 
String
parameter representing the response body. For example, to return a simple HTML document, you can do this: 

          
           
response.setContent("<html><head><title>My HTML Document</title></head><body>This is my HTML document</body></html>");

Returning a Different Response Body Depending on the Request Method

If you need to return a different response body depending on the HTTP request method (e.g. GET vs POST), you can use the 

getMethod()
method provided by the 

          
           
MockHttpServletRequest
class. For example, if you want to return a different response body for a GET vs a POST, you can do this: 

          
           
if(request.getMethod().equals("GET")) {
	response.setContent("<html><head><title>My HTML Document</title></head><body>This is my HTML document</body></html>");
} else if (request.getMethod().equals("POST")) {
	response.setContent("<html><head><title>My HTML Document</title></head><body>This is my HTML document for POST requests</body></html>");
}

Adding Cookies to the Response

You can add cookies to the response by using the 
addCookie()
method. This method takes a 
Cookie
object as a parameter. For example, to add a cookie with the name "foo" and the value "bar", you can do this: 

          
           
Cookie c = new Cookie("foo", "bar");
response.addCookie(c);

Adding Headers to the Response

You can add headers to the response using the 
addHeader()
method. This method takes a 
String
parameter representing the header name, followed by a 
String[]
parameter representing the values. For example, to add a header named "X-Foo" with the values "bar" and "baz", you can do this: 

          
           
String[] vals = {"bar", "baz"};
response.addHeader("X-Foo", vals);
