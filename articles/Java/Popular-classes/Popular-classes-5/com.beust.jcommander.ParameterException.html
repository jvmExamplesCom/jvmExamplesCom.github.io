com.beust.jcommander.ParameterException
is a checked exception that signals an erroneous parameter was encountered. This exception is thrown during the parsing of the parameters using JCommander.

Example Usage

Here is an example of code using the 
ParameterException
: 

          
           
try {
    //parse command line arguments
    JCommander.newBuilder().build().parse(args);
} catch (ParameterException pe) {
    System.err.println("Error: " + pe.getMessage());
}

In this example, the command line arguments are attempted to be parsed. If any errors occur, they will be caught and an appropriate error message will be outputted.

ParameterException
is thrown when the supplied parameters have failed validation. This can mean that a required parameter was missing, an invalid value was given, or incorrect flags were used.
