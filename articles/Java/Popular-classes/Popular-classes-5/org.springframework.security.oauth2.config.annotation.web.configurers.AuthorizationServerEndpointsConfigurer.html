Understanding org.springframework.security.oauth2.config.annotation.web.configurers.AuthorizationServerEndpointsConfigurer

AuthorizationServerEndpointsConfigurer

authenticationManager()
method. Additionally, the class provides methods for configuring various components such as token enhancers, user details services, authorization code services, and token store implementations.

Example

The following is an example of how to use the 

          
           
AuthorizationServerEndpointsConfigurer
class: 

          
           
@Configuration
@EnableAuthorizationServer
public class AuthorizationServerConfig extends AuthorizationServerConfigurerAdapter {

    @Autowired
    private AuthenticationManager authenticationManager;

    @Autowired
    private TokenStore tokenStore;

    @Autowired
    private UserDetailsService userDetailsService;

    @Autowired
    private AuthorizationCodeServices authorizationCodeServices;

    @Autowired
    private TokenEnhancerChain tokenEnhancerChain;

    @Autowired
    private JwtAccessTokenConverter jwtAccessTokenConverter;

    @Override
    public void configure(AuthorizationServerEndpointsConfigurer endpoints) throws Exception {
        endpoints
                .authenticationManager(authenticationManager)
                .tokenEnhancer(tokenEnhancerChain)
                .tokenStore(tokenStore)
                .jwtAccessTokenConverter(jwtAccessTokenConverter)
                .userDetailsService(userDetailsService)
                .authorizationCodeServices(authorizationCodeServices)
                .allowRefresh(true)
                .autoApprove("read", "write");
    }
}
In this example, we have configured an 

          
           
AuthorizationServerEndpointsConfigurer
instance with an authentication manager, a token enhancer chain, a token store, a JWT access token converter, a user details service, an authorization code services, and configured it for auto approval of the "read" and "write" scopes.
