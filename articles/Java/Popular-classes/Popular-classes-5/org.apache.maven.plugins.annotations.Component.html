org.apache.maven.plugins.annotations.Component

org.apache.maven.plugins.annotations.Component is an annotation found in the Maven Plugin API. This annotation denotes a component of a plugin, and is used to bring the component into the plugin. This annotation allows components to be adapted from other components from other plugins.

Usage of org.apache.maven.plugins.annotations.Component

The following example shows how to define a component using the org.apache.maven.plugins.annotations.Component annotation:


          
           
@Component
public class MyComponent {
...
}

@Component
annotation, you can specify certain configuration options by using the attributes of the annotation. For example, you can specify whether or not the component is required, and the role of the component. 

          
           
@Component(
    required=true,
    role=MyRole.class
)
public class MyComponent {
...
}
