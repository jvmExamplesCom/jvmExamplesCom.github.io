Introduction to com.qiniu.util.Auth

com.qiniu.util.Auth is a Java library that provides an interface to the Qiniu cloud platform. It allows developers to interact with the Qiniu cloud platform in a secure and convenient way. The library provides methods to generate URLs, upload files and access data stored in the cloud.

Getting Started with com.qiniu.util.Auth

In order to use com.qiniu.util.Auth, you must first install it on your machine. Once installed, you can get started by creating an instance of the Auth class. 

          
           
Auth auth = new Auth();
The Auth class requires two parameters: the Access Key and Secret Key associated with your Qiniu account. These keys can be retrieved from the Qiniu Console. 

          
           
Auth auth = new Auth("[your_access_key]", "[your_secret_key]");
Once the Auth instance has been created, you can then use it to generate URLs for accessing data in the Qiniu cloud platform. The generateDownloadURL() method can be used to generate download URLs while the generateUploadURL() method can be used to generate upload URLs.

Using the generateDownloadURL() Method

The generateDownloadURL() method takes two parameters – the bucket name and the file name of the data to be downloaded. 

          
           
String downloadURL = auth.generateDownloadURL("[bucket_name]", "[file_name]");
The generateDownloadURL() method also accepts an optional parameter – an expiry time in seconds. This expiry time sets the length of time for which the download URL will remain valid. If this parameter is not specified, the download URL will expire after one hour. 

          
           
long expiryTime = 3600; // 1 hour
String downloadURL = auth.generateDownloadURL("[bucket_name]", "[file_name]", expiryTime);
Once the download URL has been generated, it can be used to securely download the file from the Qiniu cloud platform.

Using the generateUploadURL() Method

Similarly, the generateUploadURL() method can be used to generate upload URLs for securely sending files to the Qiniu cloud platform. The generateUploadURL() method takes three parameters – the bucket name, the file name and a map of parameters.
