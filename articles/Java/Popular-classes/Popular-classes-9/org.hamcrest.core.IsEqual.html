What is org.hamcrest.core.IsEqual in Java?

org.hamcrest.core.IsEqual is part of the Hamcrest open source library. It provides an object-oriented interface to the classic assertEquals() method found in the JUnit testing framework. org.hamcrest.core.IsEqual should be used when writing unit tests. It is especially useful when testing complex objects, such as Java beans. It allows the developer to compare two objects for equality and assert that the actual result matches the predefined expected value.
