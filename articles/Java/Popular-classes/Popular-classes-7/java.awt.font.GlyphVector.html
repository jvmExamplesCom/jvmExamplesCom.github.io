java.awt.font.GlyphVector

Java.awt.font.GlyphVector is a standard Java class used for manipulating and measuring single-byte fonts. It provides methods for creating, positioning, and transforming glyphs (or characters) on the screen.

Creating Glyphs with the GlyphVector class

The most basic way to create glyphs with the GlyphVector class is by passing a string of characters to its constructor. The following example creates a GlyphVector object from a single character.


          
           
GlyphVector glyph = new GlyphVector("a");

The GlyphVector class also supports creating multiple glyphs in one call. To do this, simply pass an array of characters instead of a single character. The following example creates a GlyphVector object from the array of characters "abcd".


          
           
char[] chars = {'a', 'b', 'c', 'd'};
GlyphVector glyphs = new GlyphVector(chars);

Positioning and Transforming Glyphs

Once a GlyphVector object has been created, you can use the setGlyphPosition() and setGlyphTransform() methods to position and transform the glyphs it contains. The setGlyphPosition() method takes two parameters, the index of the glyph to be positioned and the new x and y coordinates at which the glyph should be positioned. The following example positions a glyph at x = 100 and y = 200.


          
           
glyphs.setGlyphPosition(0, 100.0f, 200.0f);

The setGlyphTransform() method takes three parameters, the index of the glyph to be transformed, an AffineTransform object containing the new transformation, and a value indicating whether the transformation should be applied before or after the current transformation. The following example applies a scale of 2.0 to the second glyph.

t.scale(2.0f, 2.0f);
glyphs.setGlyphTransform(1, t, GlyphVector.APPLY_TRANSFORM_BEFORE);
