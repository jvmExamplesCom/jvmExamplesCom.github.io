Introduction to Java.util.stream.LongStream

Java’s LongStream is a feature of the java.util.stream package that provides an easy way to work with streams of primitive long-valued elements. By leveraging the powers of the Streams API, LongStream can provide many of the same features as those found in the java.util.stream.IntStream and java.util.stream.DoubleStream classes, such as filtering, mapping, reducing, and so on. This article will discuss the basics of how LongStream works and provide code examples to show how it can be used.

What Can You Do with LongStream?

LongStream provides a variety of useful operations for working with primitive long values, allowing developers to perform calculations using these types from within the Java Streams API. Among the operations supported by LongStream are the following:
  • Filtering – Create a Stream of long values based on a predicate.
  • Mapping – Transform long values into other values within the Stream.
  • Reducing – Combine long values into a single value, either manually or via a mathematical operation such as summing.
  • Sorting – Order the values of the Stream.
  • Aggregating – Collect values into a map or list.

LongStream myFilteredLongStream = myLongStream.filter(x -> x > 10L);

long myReducedValue = myLongStream.reduce(0L, (x, y) -> x + y);

sorted()

LongStream mySortedStream = myLongStream.sorted();
