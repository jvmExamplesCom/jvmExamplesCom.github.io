Java.awt.event.MouseMotionListener

The 

          
           
java.awt.event.MouseMotionListener
interface is for objects that want to be notified when the mouse is being moved or dragged. This interface is part of the java.awt.event package, which contains all the events used by AWT components. To make a class receive mouse motion events, it needs to implements this interface. The methods that are implemented must be able to respond to mouse movement events generated by the user.

Methods in MouseMotionListener Interface

There are two methods: 
mouseMoved()
and 
mouseDragged()
, that can be implemented to handle mouse motion events.

mouseMoved() Method

The 
mouseMoved()
method receives an instance of 
MouseEvent
when the mouse is moved in the area associated with the object implementing the 
MouseMotionListener
interface. Here's an example of how to implement this method: 

          
           
@Override
public void mouseMoved(MouseEvent e) {
    System.out.println("Mouse moved");
}

mouseDragged() Method

The 
mouseDragged()
method is called when the mouse button is pressed and the mouse is moved in the area associated with the object implementing the 
MouseMotionListener
interface. This method also expect to receive an instance of 
MouseEvent
. Here's an example of how to implement this method: 

          
           
@Override
public void mouseDragged(MouseEvent e) {
    System.out.println("Mouse dragged");
}

Implementing MouseMotionListener

To make your class be able to receive mouse motion events, you must add the 

MouseMotionListener
interface to your class declaration. Then, you need to override both 
mouseMoved()
and 
mouseDragged()
methods from the 
MouseMotionListener
interface. Here's an example of a simple class implementing the 
MouseMotionListener
interface: 

          
           
public class MyMouseMotionListener implements MouseMotionListener {
    @Override
    public void mouseMoved(MouseEvent e) {
        System.out.println("Mouse moved");
    }

    @Override
    public void mouseDragged(MouseEvent e) {
        System.out.println("Mouse dragged");
    }
}

Using MouseMotionListener

MouseMotionListener
interface and overrides the methods, you need to add this class to the component that you want to receive mouse motion events. You can do this by calling the 

          
           
addMouseMotionListener()
method and passing an instance of your 

          
           
MyMouseMotionListener
class as argument. Here's an example of how to add your 

          
           
MyMouseMotionListener
class to a component: 

          
           
MyMouseMotionListener listener = new MyMouseMotionListener();
myComponent.addMouseMotionListener(listener);
