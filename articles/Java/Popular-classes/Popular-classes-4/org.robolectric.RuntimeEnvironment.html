Introduction to RuntimeEnvironment Class in Robolectric

The 
RuntimeEnvironment
class in Robolectric is a utility class that provides access to various properties and resources of the application environment. Features of RuntimeEnvironment

The RuntimeEnvironment class has several convenient methods that can be used to access application properties, such as:
