EventBus in Java

EventBus is a powerful tool for communication between components in Java. It is part of the org.greenrobot.eventbus library and allows developers to create custom events that can be passed between one or more components.

Creating a New Event

To create a new event, a developer must define an Event class, which extends org.greenrobot.eventbus.Event, like so:


          
           
public class MyNewEvent extends Event {
    public final String message;

    public MyNewEvent(String message) {
        this.message = message;
    }
}

The Event class contains two constructors. One takes no arguments, the other takes one argument and sets a property in the object. This property can be accessed from other components that have received the event.

Registering a Subscriber

To receive an event, a developer must register a Subscriber, which is an interface that responds to events. To register a Subscriber, a developer must call the subscribe() method of EventBus, like so:


          
           
EventBus.getDefault().subscribe(new Subscriber() {
    @Override
    public void onEvent(MyNewEvent event) {
        //do something with the event
    }
});

Posting an Event

Once a Subscriber has been registered, a developer can post an Event, which will be delivered to all registered Subscribers. To post an Event, a developer must call the post() method of EventBus, like so:


          
           
EventBus.getDefault().post(new MyNewEvent("message"));

This will cause all registered Subscribers to receive the event, and do something with it.

Unregistering a Subscriber
