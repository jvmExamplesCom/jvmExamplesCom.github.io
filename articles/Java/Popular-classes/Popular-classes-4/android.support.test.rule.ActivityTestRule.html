android.support.test.rule.ActivityTestRule

Android Support Test Rule is an important library in the Android framework for testing activities. It provides a set of rules which govern how activities and their associated states are tested. The purpose of the rule is to ensure reliable, repeatable tests of activities.

Example Code

For example, consider the below code snippet which uses ActivityTestRule to create and start an instance of an activity:


          
           
public class ExampleActivityTest { 
  private ActivityTestRule<ExampleActivity> mActivityRule = new ActivityTestRule<>(ExampleActivity.class); 
  
  @Before public void setUp() { 
    mActivityRule.launchActivity(new Intent()); 
  } 
  
  @Test public void testActivity() { 
    onView(withId(R.id.view_example)) 
        .check(matches(isDisplayed())); 
  } 
}
In this example, the 
ActivityTestRule
is used to create an 
ExampleActivity
instance and launch it. It also provides methods such as 
launchActivity
and 
finishActivity
which can be used to launch and finish activities respectively.

Conclusion

ActivityTestRule is a powerful library which provides a set of rules to facilitate reliable, repeatable tests of activities and their associated states.
