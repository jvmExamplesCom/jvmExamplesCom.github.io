To create a FloatingActionButton, you need to use FloatingActionButton.Builder class. The following code example shows how to create one:


          
           
FloatingActionButton fab = new FloatingActionButton.Builder(this)

           .setBackgroundColor(Color.parseColor("#303F9F"))
           .build();
