javafx.beans.value.ChangeListener
interface is a part of the JavaFX API that is used when dealing with object properties, particularly when they are changed. Create a ChangeListener

Creating a ChangeListener is a relatively straightforward process. All you have to do is implement the ChangeListener interface, implement its abstract method "changed" and provide a custom implementation. ChangeListener<String> listener = new ChangeListener<String>() {
    @Override
    public void changed(ObservableValue<? extends String> source, String oldValue, String newValue) {

    }

ReadOnlyObjectProperty<String> property = ...;
