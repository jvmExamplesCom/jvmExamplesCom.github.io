javax.swing.tree.DefaultTreeCellRenderer

The javax.swing.tree.DefaultTreeCellRenderer class provides a basic implementation of the javax.swing.tree.TreeCellRenderer interface. It is used to render the default user interface for nodes in a JTree component. This class allows customizing the look and feel of tree nodes through an instance of the TreeCellRenderer interface.

Methods

The following methods are provided by the DefaultTreeCellRenderer class:

  • getLeafIcon()
    – returns the icon used to represent leaf nodes in the tree.
  • getOpenIcon()
    – returns the icon used to represent open folders in the tree.
  • getClosedIcon()
    – returns the icon used to represent closed folders in the tree.

getTextSelectionColor()
    – returns the color used to denote the selection of text in the tree.

getBackgroundSelectionColor()
    – returns the color used to denote the selection of the background in the tree.
  • 
            
             
getBorderSelectionColor()
    – returns the color used to denote the selection of the border in the tree.

Code Examples

The following code example demonstrates how to create a new instance of a DefaultTreeCellRenderer:


          
           
DefaultTreeCellRenderer renderer = new DefaultTreeCellRenderer();

The following code example demonstrates how to set the icons for open and closed folders in the tree:


          
           
ImageIcon openIcon = new ImageIcon("open_folder.png");
ImageIcon closedIcon = new ImageIcon("closed_folder.png");

renderer.setClosedIcon(closedIcon);
