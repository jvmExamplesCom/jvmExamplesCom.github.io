Introduction to com.fasterxml.jackson.core.JsonGenerator

The 

          
           
com.fasterxml.jackson.core.JsonGenerator
class is an important part of the Jackson Core package which provides programmatic methods for writing JSON content from Java. This class is used to convert a Java object into an equivalent JSON string using a specific set of formatting rules and features. The JsonGenerator also has the ability to write JSON as a stream, making it easier to work with large amounts of data. In this article, we will learn how to use the com.fasterxml.jackson.core.JsonGenerator class to create JSON output in Java.

Creating a new JsonGenerator

To start creating JSON content with the JsonGenerator, we first need to create a new instance of the JsonGenerator class. We can do this by using the static factory method JacksonFactory.createJsonGenerator() on the JsonFactory class, passing in the output stream we want to write the JSON to. 

          
           
JsonFactory factory = new JsonFactory(); 
JsonGenerator jsonGenerator = factory.createJsonGenerator(System.out);

Writing the JSON Output

Once we have created a new JsonGenerator instance, we can start writing the output by using the writeStartObject() and writeEndObject() methods. These methods allow us to create a “top-level” object that contains all of our other objects and values. In this example, we are creating a top-level object that contains two other objects, “foo” and “bar”. 

          
           
jsonGenerator.writeStartObject(); 
jsonGenerator.writeObjectFieldStart("foo"); 
jsonGenerator.writeStringField("name", "John"); 
jsonGenerator.writeBooleanField("isMale", true); 
jsonGenerator.writeEndObject(); 
jsonGenerator.writeObjectFieldStart("bar"); 
jsonGenerator.writeStringField("name", "Jane");

jsonGenerator.writeEndObject(); 
jsonGenerator.writeEndObject();

      "isMale" : true 
   },

      "name" : "Jane", 
      "isMale" : false 
   }
}

Closing the JsonGenerator

Once you’re finished writing your JSON output, make sure to close the JsonGenerator by calling the close() method. If you forget to call close(), you won’t be able to write any additional output to the underlying output stream. 

          
           
jsonGenerator.close();
