javax.mail.internet.MimeMessage

javax.mail.internet.MimeMessage is an API that provides the ability to compose and parse MIME messages. It makes it easy to create and manipulate MIME messages, which are widely used in email communications. This API can be used to create both text and HTML messages, and is also used to attach files.

Creating a MimeMessage

The following example shows how to create a basic MimeMessage using the javax.mail.internet.MimeMessage API.


          
           
Session session = Session.getDefaultInstance(props);
MimeMessage message = new MimeMessage(session);
message.setFrom("my@example.com");
message.addRecipient(Message.RecipientType.TO, "recipient@example.com");
message.setSubject("My Subject");
message.setText("Hello world!");
message.saveChanges();

Attaching a File

The following example shows how to attach a file to a MimeMessage using the javax.mail.internet.MimeMessage API. This example assumes that the file being attached has already been created.


          
           
MimeBodyPart attachment = new MimeBodyPart();
File file = new File("/path/to/file.txt");
DataSource source = new FileDataSource(file);
attachment.setDataHandler(new DataHandler(source));
attachment.setFileName(file.getName());
Multipart multipart = new MimeMultipart();
multipart.addBodyPart(attachment);
message.setContent(multipart);
message.saveChanges();

String contentType = message.getContentType();
if (contentType.startsWith("text/plain")) {
    String content = (String) message.getContent();
} else if (contentType.startsWith("multipart/")) {
    Multipart multipart = (Multipart) message.getContent();
    for (int i = 0; i < multipart.getCount(); i++) {
        BodyPart part = multipart.getBodyPart(i);
        String type = part.getContentType();
        if (type.startsWith("text/plain")) {
            String content = (String) part.getContent();
        } else if (type.startsWith("application/octet-stream")) {
            byte[] content = (byte[]) part.getContent();
        }
    }
