Introduction to org.apache.commons.cli.CommandLine

Options

new Option()

CommandLineParser.parse()

args[]

Once the CommandLine instance has been created, the user can use its various methods to check for the presence and value of any given option specified by the user. public static void main(String[] args) {
	Options options = new Options();
	options.addOption("v", false, "verbose");
