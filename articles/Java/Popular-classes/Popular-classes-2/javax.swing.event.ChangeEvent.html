javax.swing.event.ChangeEvent

The 

          
           
ChangeEvent
class is a part of the Java Swing package ( 

          
           
javax.swing
) that is used to indicate that something has been changed in a Swing component. This event is typically fired as a result of an action by a user or an application. The 

          
           
ChangeEvent
class provides methods for getting the source of the change, an object that identifies the type of change, and a time stamp indicating when the change occurred.

Constructor

The 

          
           
ChangeEvent
class has several different constructors for creating new instances of the class. These constructors are listed below. All of these constructors take a reference to the changing object as their first parameter. 

          
           
public ChangeEvent(Object source)
public ChangeEvent(Object source, Object type)
public ChangeEvent(Object source, Object type, long timestamp)

Methods


          
           
public Object getSource()
public Object getType()
public long getTimestamp()
The 

          
           
getSource()
method is used to get the source of the change. This will be the same object used to construct the 

          
           
ChangeEvent
. The 

          
           
getType()
method is used to get the type of change that occurred. This object is typically used to identify a specific type of change. Lastly, the 

          
           
getTimestamp()
method is used to get the time when the change occurred, in milliseconds since the epoch.

Example

Below is an example of how to use the 

          
           
ChangeEvent
class. This example creates a 

          
           
ChangeEvent
with a type and timestamp, and then prints out the source, type and timestamp. 

          
           
MyObject obj = new MyObject();
ChangeEvent evt = new ChangeEvent(obj, "valueChanged", System.currentTimeMillis());

System.out.println("Source: " + evt.getSource());
System.out.println("Type: " + evt.getType());
System.out.println("Timestamp: " + evt.getTimestamp());
