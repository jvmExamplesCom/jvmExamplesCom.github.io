java.time.temporal.ChronoUnit

The 

          
           
java.time.temporal.ChronoUnit
enum is a date-time class that represents the concept of a standard temporal unit such as days, weeks, hours, and so on. It provides access to units of time that are not covered by the java.time package and its subpackages.

Date-Time Unit Representation

In Java, each unit of time is represented with an enum value from the 

ChronoUnit
enumeration. A 
ChronoUnit
object can also be obtained from a specific 
DateTime
object or a 
LocalDateTime
object. For example, the enum value representing years is returned when the 
getYears()
method is called on a 
LocalDateTime
object.
