Eclipse SWT Widgets Menu

The org.eclipse.swt.widgets.Menu class is part of the Eclipse Standard Widget Toolkit (SWT), and its purpose is to create menus for the user interface of an application.

A menu is a hierarchical list of items, where each item can be associated with a command that is executed when it is selected. A menu can contain one or more sub-menus, which are called cascade menus. There can also be multiple menus open at once on a given window.

Creating a Menu

Creating a menu is relatively simple — you first create a 

Menu
object and then add child 
MenuItem
objects to it. Here is an example of creating a menu containing two menu items: 

          
           
Menu menu = new Menu(shell);
MenuItem item1 = new MenuItem(menu, SWT.PUSH);
item1.setText("Item 1");
MenuItem item2 = new MenuItem(menu, SWT.PUSH);
item2.setText("Item 2");

Adding a Cascade Menu

To add a cascade menu to the menu, you need to create a 

Menu
object and then set it as the parent of the menu item that will act as the cascade menu. Here is an example of creating a cascade menu with two items: 

          
           
Menu cascadeMenu = new Menu(menu);
MenuItem item3 = new MenuItem(cascadeMenu, SWT.PUSH);
item3.setText("Item 3");
MenuItem item4 = new MenuItem(cascadeMenu, SWT.PUSH);
item4.setText("Item 4");
MenuItem cascade = new MenuItem(menu, SWT.CASCADE);
cascade.setText("Cascade Menu");
cascade.setMenu(cascadeMenu);

Adding Radio Items

To add a radio item to a menu, you use the 
SWT.RADIO
style when creating the 
MenuItem
. You can also specify a group of related radio items by providing the same value for the 
group
argument when creating each item. This ensures that selecting one of the radio items deselects all of the others. Here is an example of creating two related radio items: 

          
           
MenuItem radio1 = new MenuItem(menu, SWT.RADIO, 0, "Radio 1", 0, group);
MenuItem radio2 = new MenuItem(menu, SWT.RADIO, 1, "Radio 2", 0, group);

Adding Check Items

To add a check item to a menu, you use the 
SWT.CHECK
style when creating the 
MenuItem
. Here is an example of creating a check item: 

          
           
MenuItem check = new MenuItem(menu, SWT.CHECK);
check.setText("Check Me");

Adding Separator Items

To add a separator item to a menu, you use the 
SWT.SEPARATOR

MenuItem

new MenuItem(menu, SWT.SEPARATOR);
