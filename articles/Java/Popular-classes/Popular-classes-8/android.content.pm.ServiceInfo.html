android.content.pm.ServiceInfo

android.content.pm.ServiceInfo is a component of Android that provides access to service-related information and meta-data associated with an application package. It stores information such as service name, enabled state, exported flags, Intent filters, and permissions.

Code Examples

This example shows how to create a ServiceInfo object using the package manager:


          
           
PackageManager pkgManager = getPackageManager();
ServiceInfo serviceInfo = pkgManager.getServiceInfo(
        new ComponentName("com.example.app", "com.example.app.MyService"),
        PackageManager.GET_SERVICES);

This code snippet checks whether the ServiceInfo is enabled:


          
           
if (serviceInfo.enabled) {
    // Service is enabled
}
To set the ServiceInfo's enabled state: 

          
           
serviceInfo.enabled = true;

To retrieve the service's Intent filter information:


          
           
IntentFilter filter = serviceInfo.filter;
To set the service's Intent filter information: 

          
           
serviceInfo.filter = filter;
To retrieve the service's permission information: 

          
           
String permission = serviceInfo.permission;
To set the service's permission information: 

          
           
serviceInfo.permission = permission;
To retrieve the service name: 

          
           
String serviceName = serviceInfo.name;
To set the service name: 

          
           
serviceInfo.name = serviceName;
To retrieve the service's exported flags: 

          
           
int exported = serviceInfo.exported;
To set the service's exported flags: 

          
           
serviceInfo.exported = exported;
