org.apache.commons.io.LineIterator

The 

          
           
org.apache.commons.io.LineIterator
is a class designed to facilitate easy and efficient line-based iteration over a Reader. It allows the programmer to iterate over the lines of the Reader in much the same way as the Scanner class. This class is more efficient than the Scanner and is more suited to large readers. The 
LineIterator
class is implemented from the 
Iterator
interface inherited from Java's core 
Collection
framework. An instance of this class can be initialized with a 
Reader
or an 
InputStream
. It provides the functionality to read lines from the readers.

Methods of LineIterator class

The 
LineIterator
class provides several methods for easy manipulation of the reader. The most important ones are listed below: 
  • hasNext()
    - checks if there is another line to read
  • nextLine()
    - retrieves the next line from the reader
  • close()
    - closes the reader

Example Usage of LineIterator


          
           
LineIterator itr = new LineIterator("path/to/file");

while (itr.hasNext()) {
    String line = itr.nextLine();
    System.out.println(line);
}

itr.close();

LineIterator
class. The 
hasNext()

nextLine()
