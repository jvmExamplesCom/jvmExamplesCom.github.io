The exists method is used to check if a Marker with the specified name exists. Let's look at a few code examples to see how these methods work. Marker myMarker = MarkerFactory.getMarker("my_marker");

LOGGER.debug(myMarker, "This is my message");

Boolean markerExists = MarkerFactory.exists("my_marker");
