JavaFX’s Scene Control MenuItem

The 

          
           
javafx.scene.control.MenuItem
is an important class within the JavaFX Scene Graph API. It allows developers to create a menu item, which can contain either a text label or an image. These items can be added to menus, context menus, and sub-menus.

Creating a MenuItem

To create a 
MenuItem
, you first need to create a new instance of the class with a Label, as seen below: 

          
           
MenuItem myMenuItem = new MenuItem("My Menu Item");
You can also add an Image to the 
MenuItem
if desired: 

          
           
Image icon = new Image("myIcon.png");
MenuItem myMenuItem = new MenuItem("My Menu Item", new ImageView(icon));

For quick access, you can also assign an accelerator key to the 

MenuItem
. This will allow the user to press the specified key combination to trigger the action. 

          
           
KeyCombination keyCombination = new KeyCodeCombination(KeyCode.S, KeyCombination.CONTROL_DOWN);
myMenuItem.setAccelerator(keyCombination);
You can also set a tooltip for the 
MenuItem
. This is displayed when the user hovers their mouse over it: 

          
           
myMenuItem.setTooltip(new Tooltip("My Tooltip"));

Adding MenuItems to Menus

You can add 
MenuItems
to any existing 
Menu
or 
ContextMenu
with the following code: 

          
           
menu.getItems().add(myMenuItem);
contextMenu.getItems().add(myMenuItem);
Or if you would like to add a 
MenuItem
to the end of the list, you can use the following code: 

          
           
menu.getItems().addAll(myMenuItem);
contextMenu.getItems().addAll(myMenuItem);

Handling User Actions

When the user clicks on the 
MenuItem
, they will trigger an 
ActionEvent
. We can handle this event with the following code: 

          
           
myMenuItem.setOnAction(new EventHandler<ActionEvent>() {
    @Override
    public void handle(ActionEvent event) {
        // Handle user action
    }
});

Conclusion

The 

          
           
javafx.scene.control.MenuItem
provides a way to easily create menu items for the user to interact with. This class is incredibly powerful and can be used to create powerful user interfaces.
