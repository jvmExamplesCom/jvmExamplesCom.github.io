RippleDrawable is a drawable class in the Android framework that provides a ripple effect when touched. It can be used to create a ripple effect on any view, including buttons, images and backgrounds. RippleDrawable drawable = new RippleDrawable(rippleColor, maskDrawable, optionalEnterAnimation, optionalExitAnimation);
