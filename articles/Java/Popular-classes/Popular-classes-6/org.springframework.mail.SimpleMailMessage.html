Introduction to org.springframework.mail.SimpleMailMessage

org.springframework.mail.SimpleMailMessage is a convenience class for sending simple emails without the need for an external mail server. It can be used both for plain text and HTML messages, and allows for attachments to be included by passing in an array of File objects.
