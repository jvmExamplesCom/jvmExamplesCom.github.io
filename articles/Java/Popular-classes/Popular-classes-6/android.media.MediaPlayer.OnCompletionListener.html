android.media.MediaPlayer.OnCompletionListener

android.media.MediaPlayer.OnCompletionListener is an interface that provides a callback to be invoked when the media source has finished playing. This interface is typically used during audio playback, as it allows media sources to perform certain tasks after a song has finished playing. It is also used to play advertisements or other content that should start playing immediately after a video or audio clip has finished. It can be used to trigger the start of the next video or song in a queue.

The OnCompletionListener interface contains a single method, onCompletion(), which is called when playback of the media has completed. The onCompletion() method should have one parameter, an object of type MediaPlayer, which represents the media source that was just finished playing. The media player contains information about the media source, such as its length and position.

Example


          
           
MediaPlayer mp = new MediaPlayer();
 mp.setOnCompletionListener(new MediaPlayer.OnCompletionListener() {
 	public void onCompletion(MediaPlayer mp) {
 		// do something after the sound has finished playing
 	}
 });
 // play the media
 mp.start();

In this example, a media player is created and the onCompletionListener is set to an anonymous class implementation of the OnCompletionListener interface. The implementation of the onCompletion() method will be called when the media player has finished playing its media source. This allows us to perform certain tasks after the media has finished playing, such as playing an advertisement or starting the next video in a playlist.
