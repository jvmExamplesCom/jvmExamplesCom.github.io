Using the javafx.beans.property.StringProperty Class

The 

          
           
javafx.beans.property.StringProperty
class provides support for JavaFX application's properties. This class adds modern features to the class 

          
           
java.lang.String
. This includes support for binding and other features. In this article, we'll take a look at how to use and manipulate this class.

Creating a StringProperty

Creating a 

          
           
StringProperty
is straightforward. To create one, simply use the default constructor: 

          
           
StringProperty strProp = new StringProperty();
The initial value of the property will be populated with an empty string. If you would like to specify an initial value, you can do so by using the constructor that takes a string parameter: 

          
           
StringProperty strProp = new StringProperty("Hello World!");
The above code creates a 

          
           
StringProperty
with an initial value of "Hello World!".

Accessing and Modifying the Value of a StringProperty

The value of a 

          
           
StringProperty
can be accessed or modified using the following methods: 
  • getValue()
    - Returns the current value of the property.
  • 
            
             
setValue(String one)
    - Sets the value of the property to the specified string.
  • 
            
             
bind(ObservableValue other)
    - Binds the property to another observable value.
  • unbind()
    - Unbinds the property from any other observable values.
For example, the following code sets the value of a 

          
           
StringProperty
to "Goodbye World!": 

          
           
strProp.setValue("Goodbye World!");

IntegerProperty
: 

          
           
intProp.bind(strProp);

Using StringProperty Listeners

StringProperty also supports listeners. These can be used to detect changes in the value of the property. For example, the following code adds a listener to the property that prints out the new value when the value is changed: 

          
           
strProp.addListener((observable, oldValue, newValue) -> {
   System.out.println("The new value is: " + newValue);
});
When the value of the property is changed, the listener will be triggered and it will print out the new value.
