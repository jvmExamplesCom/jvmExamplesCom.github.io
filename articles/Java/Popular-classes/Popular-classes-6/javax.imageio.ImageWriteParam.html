javax.imageio.ImageWriteParam

The javax.imageio.ImageWriteParam class is an abstract class used to describe how an ImageWriter should write out an image as part of the Java Image I/O API. It allows for things such as controlling compression and encoding parameters of images, and even allowing the user to set which type of encoding to use.

The following example shows how the ImageWriteParam can be used to control the encoding used for an image:

ImageWriteParam iwparam = new ImageWriteParam();

// Set the encoding used for the image
iwparam.setDestinationType(ImageTypeSpecifier.createIndexed(new IndexColorModel(8, 4, new byte[]{0, (byte)255}, 0, false), 8, DataBuffer.TYPE_BYTE));

// Set the compression mode

// Set the compression type

// Set the quality of the compression
iwparam.setCompressionQuality(0.75f);
